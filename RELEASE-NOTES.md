# Rivals Eight Local 0.1.0 — experimental preview

Unofficial Windows mod for the exact tested original Rivals of Aether 2.1.9.1 executable. Adds eight local character-selection slots, extra local fighters, and a transparent eight-player HUD along the bottom.

## Included

- Independent controller slots and corrected keyboard/controller assignment.
- Expanded CPU difficulty storage, valid levels 1-9, CPU menu-state cleanup, and eight distinct character-token positions with corrected pickup eligibility. This update passed offline checks; in-game CPU verification remains pending.
- Corrected footer-control placement for compressed character cards. CPU difficulty bars and human menu controls now render in their own card, above the fighter-name caption. Rendering was captured in-game; human interaction checks remain pending.
- Eight-player native match support.
- Proportional character-selection portraits and visible Workshop Playtest panels.
- Selected fighter names beneath occupied character cards in all eight slots, including Workshop names, with proportional fitting for long names.
- Colored HUD entries, character heads and stock counts beneath percentages.
- Stage-selection input for extra slots, stage-data spawn placement, and an eight-player results screen.
- Winner portrait and name, all eight placements, individual heads, remaining stocks, and KOs on the victory screen.
- Elimination-order tracking and stock-match completion when participants occupy only extra slots.
- Workshop selections reset correctly when returning from results to character selection.
- Separate-copy installer, executable compatibility checks, launcher save backups, and comment-free source.

## Read before sharing

This is an experimental external installation, not a Steam Workshop subscription mod. It requires an owned, supported copy of the game. Eight human controllers and broad Workshop compatibility are not certified. See TESTING.md for the actual test coverage and any pending checks.

The ZIP contains only the original mod files. Do not redistribute the game directory created by the installer. Do not claim endorsement by Aether Studios or Valve.
