RIVALS EIGHT LOCAL

INSTALL OR UPDATE

1. Extract the whole ZIP into a new folder.
2. Close Rivals and keep Steam running.
3. Double-click Setup.cmd and wait for "Setup complete".
4. Double-click Launch.cmd in this same folder.
5. On first launch, accept the prompt to open the Steam Workshop page.
   Subscribe to the Local+ stage, then close the overlay with Shift+Tab.
6. Choose Local > Versus in the game.

Setup finds the Steam game automatically and reuses your existing mod
installation when present. If an older installation is in a custom folder,
open files, double-click Update.cmd, and enter that folder when asked.

Keep the files folder together with Setup.cmd and Launch.cmd. You do not
need to open it during normal use. It contains the support files, source,
license, release notes, and diagnostic records.

STORAGE

Your subscribed Workshop characters and stages are loaded from their
existing location, not copied by setup. Where supported, the mod DLL uses
a hard link so the downloaded and installed files share the same disk data.
Different drives or unsupported file systems require one small DLL copy.
Do not edit the linked DLL directly. Extract future releases into a new
folder and run Setup.cmd to update.

Setup still creates a separate copy of the base game, so the Steam files
stay untouched. Updates reuse that copy. The default installed location is
%LOCALAPPDATA%\RivalsEightLocal\Game

RESULTS SCREEN

All eight players appear in ranked rows beside the winner portrait.
Press Z on the keyboard or A on a controller to ready up. The screen
continues when all human players are ready. Press X on a controller or
Tab on the keyboard for statistics. Start or Enter continues immediately.

HELP

Windows and Steam Rivals of Aether 2.1.9.1 are required. Local Versus only.
There may be bugs. Replays are not currently a feature of this mod.
Large Workshop character combinations can run out of memory.

If setup fails, copy the error message. If the game reports an error, its
details are saved in slot-probe.log inside the installed game folder.
The launcher backs up saves and settings before each launch to:
%LOCALAPPDATA%\RivalsEightLocal\SaveBackups

The copied game shares the original save folder. To remove the mod, close
it and delete its separate installed game folder. Saves and backups remain.
Game and Workshop assets are not included. Do not distribute the copied
game. The mod code uses the MIT license in files/License.txt.
